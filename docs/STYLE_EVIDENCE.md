# 写作特征证据库（提炼自真实 985 公开本科毕设）

本文件记录 `paper/thesis_template.py` 中 `STYLE_RULES` 与 `content_quality_checklist`
两条标尺的「实证来源」。目的是让导师与组员看到：我们的反 AI 腔 / 内容严谨度标尺
不是凭空设定的，而是对照真实 985 范文提炼出的「写法特征」。

## 来源（均为网络公开、可自由访问页面，仅做本地特征分析）

- 清华大学计算机科学与技术系 2008 本科毕设《一种基于 Renew 的有色网元对象协议的设计与实现》
  （挂在个人 / 项目公开页面 `soft.cs.tsinghua.edu.cn`）
- 北京大学计算机科学与技术系 2024 本科毕设《无监督学习范式下域迁移与场景重建技术研究》
  （导师刘家瑛，挂在 GitHub Pages 公开）

两份 PDF 已下载至 `corpus/`（已在 `.gitignore` 排除，绝不入库、绝不外传），
仅用于提取「写法特征」，未复制任何原文内容。

## 关键发现（直接反哺模板标尺）

1. **章节数按研究类型浮动**：北大 2024 为 5 章（引言 + 国内外研究现状 + 两项方法 + 总结与展望），
   并非固定 8 章；但「前置（中英文摘要 + 目录）+ 后置（参考文献 + 致谢 + 附录）齐备、
   且每章带『本章小结』」是跨校共性硬要求。
   → 模板 8 章定为「实证 / 理工科型默认骨架」，研究型可在 planner 阶段调整章数与标题。
2. **摘要写法**：以概念定义或具体问题切入，无「近年来……引起广泛关注」式套话；
   创新点用「针对 X 问题，本文提出……」分条陈述，每条含方法 + 结果。
3. **文献综述**：按「主题 / 待解决问题」组织，每条前人工作点明其立场与局限，
   并以「然而……」引出本文差异；绝非逐篇流水账罗列。
4. **本章小结**：归纳本章核心工作，指出相关局限，并铺垫后文（如「为后文……所做的改进工作进行铺垫」）。
5. **总结章**：分条列出创新点 / 独立见解，每条「针对 X 问题，本文提出 Y，在 Z 上展现出……」；
   未来展望须基于本文具体局限给出可落地方向，避免空话。
6. **引用规范**：正文用 `[编号]` 上标式标注；参考文献含作者、标题、出处、年份，
   近五年文献占相当比例（北大范文参考文献以 CVPR / ICCV / ECCV / NeurIPS 等顶会近五年文献为主）。

## 合规边界

- 仅提取写法特征，未将任何原文内容写入模板或论文生成器。
- PDF 仅留本地 `corpus/`，已排除出版本库，不外发、不传播。
- 模板输出的是「质量基线」，落稿格式按使用者所在学校模板套用，不绑定任何单一院校格式。
