# AutoResearch 论文质量评分标准（Rubric）

> 本文件是 EvalAgent 六维评分的**事实来源与溯源依据**。
> 设计原则：与 `thesis_template.py`（模板）同一思路——**不自己拍脑袋定标准**，而是拉取清北及多所 985 高校公开可查的本科毕设/毕业论文评分办法，提炼出公认的维度、权重与等级阈值，再映射为可机器执行的确定性检查。
>
> 说明：本评分衡量「论文符合这套公认工程化规则到什么程度」，**不等于答辩委员会最终给分**；导师最看重的主观项（选题创新性深度、批判性思维）规则暂未完全覆盖，已在局限中注明。

---

## 一、溯源：各高校真实评分维度

| 来源 | 维度/权重（原文摘录） |
|---|---|
| **清华大学** 优秀本科毕业论文标准 / 评分细则 | 优(90–100)：概念准确、结构严谨、逻辑性强、语言流畅；选题好、内容充实、综合运用专业知识、有独特见解与鲜明创新；材料典型真实；结构严谨文理通顺；参考文献以近三年核心期刊/硕论为主；研究思路清晰、方法得当、结果合理。 |
| **哈尔滨工业大学(威海)** 本科生优秀毕业设计(论文)评选办法 | 选题(10%) / 调研论证(20%) / 研究方法及内容(35%) / 创新与成效(25%) / 撰写质量(10%)。明确给出权重，是本课权重的主要锚点。 |
| **北京大学** 本科学位论文成绩评定标准（法学院/马院/政府管理学院） | 七项：①选题是否具有理论或实践意义 ②文献资料是否充分详实 ③论文结构是否逻辑清晰 ④文字表述是否准确流畅 ⑤观点是否具有新颖性 ⑥引用注释是否合乎规范 ⑦是否存在抄袭。百分制，60 及格、85 优秀。 |
| **中国科学技术大学** 本科毕业论文评阅标准 | 1 选题意义（选题目的、研究意义） 2 写作安排（文献调研、工作量） 3 逻辑构建（层次体系、逻辑结构） 4 专业能力（综合应用、分析解决、创新与特色）。 |
| **东北大学** 本科毕业设计质量评价方案 | 选题质量 18%（目的明确/难易适当/理论或实际意义）；能力水平 52%（综合运用知识 12、应用文献 9、设计实验研究能力 10、计算、创新）；另有撰写表达、学术规范。 |
| **武汉大学** 本科毕业论文质量参考标准 | 论文选题 10（与专业结合、有新意、理论/应用价值）；理论基础 15（查阅最新文献、综述质量高、理论分析清楚）。 |
| **辽宁大学** 本科毕业论文质量标准 | 学术规范 30（文字表达 10、格式规范 10、学术诚信 10）；专业能力 25；逻辑构建 10；写作安排 10；设计选题 15。 |

**共性结论**：无论各校表述差异，公认的本科毕设评价维度高度一致，可归纳为六个：
**选题意义、文献调研、逻辑构建、专业能力（方法与内容）、创新、撰写质量与学术规范**。

## 二、本系统的六维映射与权重

权重以**哈工大(威海)明确权重**为主锚点，参照东北大学「能力水平占 52%」、武大/辽大学术规范占比，综合拟定，总权 100%。

| # | 系统维度（键） | 对应真实 rubric | 权重 | 主要检查（确定性） |
|---|---|---|---|---|
| 1 | **选题意义** `topic_sig` | 清华「选题好/有现实意义」；北大①；哈工大选题10%；东北选题18%；中科大选题意义 | **12%** | 绪论是否陈述**现实/理论相关性**（临床/应用/需求）与**研究空白**（缺乏/尚未/差距），二者兼备方满分 |
| 2 | **文献调研** `literature` | 哈工大调研论证20%；北大②；武大理论基础15%；东北应用文献9% | **15%** | 候选文献质量（数量/被引/时效，quality_score）；正文综述是否按主题组织并定位本文差异（引用≥3 且含「本文/差异/局限」） |
| 3 | **逻辑构建** `structure` | 中科大逻辑构建；清华「结构严谨」；北大③ | **10%** | 对照章节 rubric 检查核心章（摘要/绪论/综述/方法/实验/结果/讨论/结论/参考文献）是否齐全 |
| 4 | **专业能力·方法与内容** `methodology` | 哈工大研究方法及内容35%；东北能力水平52%；中科大专业能力 | **33%** | 实验是否含对比基线/方差/随机种子/交叉验证/消融；全文是否承载真实数值；正文`[N]`引用与参考文献是否对应、无幽灵条目 |
| 5 | **创新** `innovation` | 哈工大创新与成效25%；北大⑤；中科大创新与特色 | **15%** | 结论章是否明确创新点/独立见解/本文贡献，并区分本人与他人工作 |
| 6 | **撰写质量与学术规范** `writing_norms` | 哈工大撰写质量10%；辽大学术规范30%；北大④⑥⑦ | **15%** | 反 AI 腔（套话/排比/单句成段）；图表公式编号规范；参考文献≥20 篇且含近五年/近两年文献 |

**零编造硬门 `consistency`（独立，不计入加权）**：复用 `audit_consistency` 的裁决表 vs 结论一致性 + 素材谎言检测。**硬门必须满分**，否则一律判不及格重做——这是系统「零编造」底线的守门员，叠加在 rubric 之上（真实 rubric 默认论文真实，本系统额外用机器强制兜底）。

## 三、等级阈值（五级分制）

沿用清华/哈工大优秀毕业设计「≥90」线；北大以 85 为优秀线，本系统取更严格的 **90** 作为优秀阈值，并在输出中标注。

| 等级 | 区间 | 含义 |
|---|---|---|
| 优秀 | ≥ 90 | 达到 985 优秀毕业设计水平 |
| 良好 | 80 – 89 | 达到良好毕业设计水平 |
| 中等 | 70 – 79 | 达到中等水平 |
| 及格 | 60 – 69 | 勉强达到基本要求 |
| 不及格 | < 60 | 未达基本要求，需重做 |

**通过判定**：`passed = (consistency 硬门满分) 且 (overall ≥ 60)`。低于 60 即不及格。

## 四、局限与后续

- 主观深度项（选题创新性的「新意」程度、批判性思维、学术视野）目前以关键词/结构信号近似，未做语义级评判；后续可接入 LLM 评判作为辅助，但保留确定性检查为硬门。
- 「选题意义」判定依赖绪论显式或隐式陈述相关性与研究空白；纯文字游戏（堆砌术语但无实质空白）可能误判为通过，需结合 content_quality 的实验严谨度交叉验证。
- 文献质量分依赖 LiteratureAgent 的 `quality_score`（被引+时效归一 0~1）；OpenAlex 被引数缺失时会低估，已用 `.get` 防御。

## 五、深圳技术大学专属标尺（公文通 / 2025 届毕设通知）

除通用 985 rubric 外，深技大另有硬性格式与查重要求，已落地为确定性检查（见 `agents/eval_agent.py` 的 `check_format_compliance` 与 `check_duplication`）：

| 指标 | 深技大要求 | 本系统处理 |
|---|---|---|
| 正文字数 | ≥12000 字 | `check_format_compliance` 校验全文中文字数 ≥12000 |
| 参考文献 | ≥10 篇，其中外文 ≥2 篇 | 生成侧抓 20 篇外文文献；评分子统计参考文献块含拉丁字母条目 ≥2 |
| 中文摘要 | ≥200 字 | 校验摘要块中文字数 |
| 关键词 | 3–4 个，每词 ≤6 字 | 写作提示词 + 确定性兜底双重约束；评分校验数量与长度 |
| 前置结构 | 封面、诚信声明、目录、摘要、正文、参考文献、致谢、英文摘要 | 生成侧补齐「封面」「诚信声明」（原缺两项） |
| 查重率 | 知网重合率 <30% 合格，校级优秀 <20% | `check_duplication` 本地预估（论文内自重复 + 与参考文献标题逐字复刻），**不含知网全网库**，仅作提交前自检；预估 ≥30% 告警、≥20% 提示 |
| AIGC 检测 | 多校要求特征值 ≤20%（深技大未明示但趋势） | 反 AI 腔检查（套话/排比/单句成段）间接降低 AIGC 特征 |

> 注：查重为本地预估，无法替代知网；正式提交前仍须用学校知网系统做全网查重复核。
